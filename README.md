# 💰 مصروفاتي — ميزانية البيت

موقع بسيط لإدارة مصروفات البيت الشهرية، مستوحى من الشيت الأصلي.

## ✨ المميزات
- ✅ إدخال تفصيلي: كل حاجة بسعرها + تفاصيل + تاريخ + البند
- ✅ البنود: تسويقة الأسبوع، سمك ولحمة، مستلزمات البيت، باقات شخصية، باقات العائلة، كهرباء، علاج، ملابس، عناية شخصية، اكل سكن، مواصلات، اشتراكات، خروجات، أقساط
- ✅ تسجيل الدخل وإجمالي مصروفات الشهر والباقي من الفلوس
- ✅ إجمالي كل بند على حدة + مخطط دائري للتوزيع
- ✅ فلترة حسب الشهر + بحث في السجل
- ✅ حفظ تلقائي في المتصفح (LocalStorage)
- ✅ وضع ليلي 🌙 / نهاري ☀️
- ✅ تصدير CSV يفتح في Excel + طباعة

## 🚀 التشغيل
افتح `index.html` في المتصفح مباشرة، أو استضفه على GitHub Pages.

## 📤 الرفع على GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/masrofati.git
git push -u origin main
```
ثم فعّل GitHub Pages من Settings → Pages → Branch: main.
